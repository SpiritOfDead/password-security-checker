# 🔐 Password Security Checker – Python Project

A **Python-based tool** that analyzes the strength of a password based on its length, use of uppercase and lowercase letters, digits, and special characters.  
This project demonstrates practical skills in **cybersecurity, automation, and regular expressions**.

---

## 🧠 Features
- Evaluates password strength in real time.  
- Detects the presence of uppercase, lowercase, numbers, and symbols.  
- Provides feedback from "Very Weak" to "Very Strong".  
- Easy to customize and extend.

---

## 🛠️ Technologies Used
- Python 3  
- Regular Expressions (`re` module)
